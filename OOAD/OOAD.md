# Object-Oriented Analysis and Design

## Purpose

Provide the analysis and design view of SentinelBiz using domain concepts,
responsibilities, collaborations, and system boundaries.

## Analysis approach

1. Identify actors and goals.
2. Identify domain concepts and relationships.
3. Define system responsibilities.
4. Allocate responsibilities to cohesive components.
5. Validate the design against requirements.

## Design principles

- Keep business rules independent from delivery mechanisms.
- Give each object a clear responsibility.
- Prefer explicit boundaries and stable contracts.
- Keep infrastructure concerns behind abstractions.
