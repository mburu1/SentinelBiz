# SentinelBiz UML Specification

The UML set documents structure and behavior before implementation.

## Required diagrams
- Use-case diagram
- Domain/class diagram
- Sequence diagrams
- Activity diagrams
- State diagrams
- Component diagram
- Package/module diagram
- Deployment diagram

Diagrams should remain synchronized with the OOAD, architecture, database, AI, ML, security, and testing specifications.
