# SentinelBiz Documentation Specification

This directory is the documentation-only design baseline for SentinelBiz.

## Contents
- `ooad/` — object-oriented analysis and design
- `uml/` — UML structural and behavioral models
- `database/` — PostgreSQL, MongoDB, data governance
- `architecture/` — system architecture, bounded contexts, integration, ADRs
- `ai/` — LLM, RAG, guardrails, evaluation
- `ml/` — ML.NET strategy and lifecycle
- `security/` — security architecture, threats, AI security, tenancy/audit
- `testing/` — testing strategy and quality gates

## Status
Documentation only. No implementation is specified or included here.

## Source of truth
The SentinelBiz root `README.md` remains the master project specification. These documents decompose that specification into design artifacts that must be agreed before implementation begins.
