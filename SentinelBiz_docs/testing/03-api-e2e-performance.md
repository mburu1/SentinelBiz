# API, E2E, and Performance Testing

## API/contract
Validate request/response contracts, status codes, authorization, validation, errors, pagination, and compatibility.

## Postman/Newman
Postman collections should represent externally observable API workflows and be runnable through Newman in automation.

## E2E
Validate the core journey:
Registration → Ideation → Readiness → Planning → Market Entry → Support.

## Performance
Measure latency, throughput, concurrency behavior, resource utilization, database behavior, messaging behavior, and AI/ML latency where relevant.
