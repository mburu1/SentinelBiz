# SentinelBiz OOAD — Actors and Use Cases

## Actors

| Actor | Responsibility |
|---|---|
| Entrepreneur | Learns, develops a business idea, completes assessments, plans, and receives support |
| Advisor | Reviews cases, provides guidance, handles escalations |
| Program Manager | Configures programs, monitors cohorts and outcomes |
| Administrator | Manages tenants, users, permissions, policies, and platform configuration |
| AI Assistant | Provides grounded contextual assistance |
| ML Services | Produce predictive scores and recommendations |
| External Systems | Provide messaging, identity, notifications, or integration events |

## Core use cases
1. Register and authenticate.
2. Establish entrepreneur/business profile.
3. Create and refine business idea.
4. Complete learning modules.
5. Assess investment readiness.
6. Create and maintain business plan.
7. Perform financial/business calculations.
8. Receive AI-assisted guidance.
9. Ask knowledge-grounded questions.
10. Generate or refine business-plan content.
11. Receive readiness/risk predictions.
12. Receive recommendations.
13. Escalate a case to an advisor.
14. Track progress and outcomes.
15. Manage programs and cohorts.
16. Audit security-sensitive actions.

## OOAD rule
Use cases describe externally observable behavior. Domain objects and application services implement the behavior; infrastructure details must not define business concepts.
