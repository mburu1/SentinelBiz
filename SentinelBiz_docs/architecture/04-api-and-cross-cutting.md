# API and Cross-Cutting Architecture

## API
- RESTful ASP.NET Core API.
- OpenAPI documentation.
- Scalar for interactive API exploration.
- Versioned contracts where compatibility requires it.
- Consistent validation, errors, pagination, filtering, and authorization semantics.

## Cross-cutting concerns
Security, tenant context, validation, logging, tracing, metrics, auditability, exception handling, correlation IDs, and idempotency where required.

## API principle
The API exposes application capabilities, not persistence implementation details.
