# ML Data, Features, and Labels

## Feature sources
Potential sources include learning progress, assessment responses, business-plan completeness, historical outcomes, engagement signals, and approved business metrics.

## Requirements
- Explicit feature definitions.
- Label provenance.
- Training/validation/test separation.
- Leakage prevention.
- Tenant/privacy review.
- Missing-data strategy.
- Feature versioning.

## Governance
A model cannot be promoted without evidence that its data is representative enough for its intended decision-support use.
